# ADR-005：验收探针用 bash 实现

- 状态：accepted
- 日期：2026-07-31
- 关联：SR-2 · NFR-1（仅 macOS）· 宪法 C2/C13

## 背景与驱动力

每阶段制品要有零摩擦可跑的验收探针；受训企业环境不应被要求先装运行时。

## 备选方案

### 选项 A：bash（macOS 自带，BSD 工具族）
- 优点：零依赖零安装；与 hooks/CI 天然同语言；受众拿到即跑
- 代价：复杂逻辑（YAML/JSON 解析、状态机）表达力差；BSD/GNU 差异是移植坑（仅 macOS 决策暂时豁免）

### 选项 B：python3（macOS 亦自带）
- 优点：表达力强，复杂校验舒服
- 代价：系统 python 版本漂移（3.9~3.13 差异）；诱惑引第三方包→破坏零依赖；对"探针应当极简"是过度武装

### 选项 C：node/deno
- 优点：前端受众熟
- 代价：需安装运行时——违背拿来即跑

## 决定

选 A。决定性理由：探针本质是"grep 结构 + 退出码"，bash 够用且零依赖；ADR-004 已把复杂度压到最低（文本块+固定格式）。

## 后果

- ✅ 探针可在任何 macOS 直接跑；CI 同脚本复用
- ⚠️ 单个探针逻辑超 ~100 行或需解析结构化数据时=信号弹，该探针单独升 python（记新 ADR，不整体迁移）
- 可复议条件：Linux 支持启动（ADR-007 复议）时补 GNU 兼容层或迁 python
