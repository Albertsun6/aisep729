# ADR-001：采用四层平台架构（真相/适配/分发/控制平面）

- 状态：accepted
- 日期：2026-07-31
- 关联：PRD 全部 US · 调研报告 v2.1 §架构设计 · 宪法 C4

## 背景与驱动力

平台须对外分发（咨询交付件）且不被单一 vendor 锁死；调研三方独立证实"无单一框架覆盖企业完整 SDLC"，缺口在控制平面。

## 备选方案

### 选项 A：全部塞进 `.claude/`（单层，Pimzino 式）
- 优点：结构最简，一个目录讲完
- 代价：业务真相绑死 Claude 工具链；Pimzino 先例已停更；换/加工具（Codex/Gemini CLI）需整体重写

### 选项 B：四层分离（L1 真相 docs/specs、L2 适配 .claude/、L3 分发 plugin、L4 控制平面）
- 优点：真相工具无关（AGENTS.md 入 LF 中立治理佐证）；各层独立演进；控制平面缺口显式补齐
- 代价：目录更多、初学者认知成本高（靠手册与脚手架缓解）

### 选项 C：双层（真相+适配，不设分发/控制平面）
- 优点：比 B 简单
- 代价：团队分发退化为"拷目录"（必腐化）；发布/审计无落点——恰好丢掉咨询差异化

## 决定

选 B。决定性理由：对外分发与企业治理是产品定位的核心（prfaq 差异化主张），A/C 都砍掉了卖点。

## 后果

- ✅ 分发与治理有原生落点；换工具只重写 L2
- ⚠️ 试点期 L4 只实配 CI 双环（其余文档化）——接受"层存在但未填满"
- 可复议条件：Agent Teams/Managed Agents GA 后 L3/L4 实现选型重估（新 ADR）
