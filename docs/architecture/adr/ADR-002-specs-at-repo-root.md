# ADR-002：specs/ 与 docs/ 放仓库根，.claude/ 仅放适配件

- 状态：accepted
- 日期：2026-07-31
- 关联：ADR-001 · 宪法 C4 · 调研冲突分析 C5

## 背景与驱动力

产物状态机的制品（prfaq/prd/spec/plan/tasks）是业务真相，必须比工具活得久。

## 备选方案

### 选项 A：`.claude/specs/`（工具目录内，Pimzino/ccpm 先例）
- 优点：所有平台相关文件一处集中
- 代价：语义错位（产物≠工具配置）；`.claude/` 常被 gitignore 惯例误伤；跨工具读取别扭；先例项目已停更

### 选项 B：仓库根 `specs/` + `docs/`（spec-kit/OpenSpec 同向）
- 优点：真相地位显式；非 Claude 工具（人/CI/其它 agent）自然可读；与 SDD 主流一致
- 代价：仓库根目录变多（脚手架统一生成，成本一次性）

## 决定

选 B。决定性理由：宪法 C4"产物是真相，工具是适配"的直接推论；主流 SDD 工具全部同向。

## 后果

- ✅ 制品可被任何工具消费；`.claude/` 可整体替换
- ⚠️ 需在手册向"习惯 .claude 集中"的用户解释一句
- 可复议条件：无（方向性决策，除非 C4 修宪）
