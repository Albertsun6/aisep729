一句话：平台本身是产品（企业培训/咨询落地包，中文）。四层架构承载六段生命周期，六人审门禁 + 服务端硬门禁控质量；绿地一键初始化、存量"体检→非破坏接入→棘轮围栏→绞杀改善"；试点 = 平台仓 + demo 业务仓，13 条 Story，5 个建设里程碑。 依据：《Claude企业级E2E研发平台-完整报告》v2.1 + 《端到端阶段划分》调研 + /req-discovery 访谈。

4 构建与交付②通过tasks→code+tests→PR→releasehooks+CI 硬门禁；③ 合并（risk-tiers 路由）；④ 放行（PRR）e2e-implement / e2e-review / e2e-releaseskill+CI 真跑 部署 demo 级
5 运营/演进④通过runbook、监控、事故回流事故→回段 1/2（runbook 由 e2e-release 产出）runbook 真做，监控文档化
6 退役拟下线deprecation 计划⑤ 退役评审（架构师+产品）e2e-retireskill 真做，demo 演练

边界铁律：未过门禁，下一段 skill 拒绝启动；门禁证据触发而非日期；密度按 risk-tiers 分档（NASA 硬 gate ↔ Amazon 一页纸）。

⑥ 制作过程选择性评审 + 试点范围红线

风险档产物评审方式
高spec/plan/ADR/constitution/门禁定义异构评审（多轮辩论）+ 你人审
中脚手架/hooks/skill 可执行部分可执行验证必过 + 单 lens AI 评审一轮
低手册正文/README/旁白稿你抽查 + 链接/拼写探针
门禁打回 ≥2 次自动升一档

试点范围红线（不做）

  • L4 managed settings / OTel→SIEM / gateway：仅文档化
  • Tier 2 权限探针实测：二期（随 L4 实配）
  • 培训 PPT / 英文文档：二期
  • 真实生产部署：demo 级即止
  • 不承诺"治好烂架构"：只看清/锁住/按数据逐步改；重构立项走⓪
