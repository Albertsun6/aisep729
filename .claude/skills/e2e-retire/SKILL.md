# e2e-retire — 阶段6：退役

> SOP 权威定义：`docs/process/stages/stage-6-retire.md`（冲突以定义文档为准并回修本文件）
> 模板：`templates/deprecation-template.md` ｜ 探针：`scripts/check-retire.sh` ｜ 契约：SPEC-23

## 硬约束（先读）

1. **第 0 步门禁校验**：`specs/<feature>/release.md` 门禁④非 `批准` → 拒绝启动（退出码 64）。没放行过生产的东西谈不上"退役"，那是砍需求（回门禁⓪）
2. **计划正文必须引用门禁④记录**（SPEC-23）：`> 上游：release.md 门禁④ 批准 @<日期>`——串锁要在文档里看得见，不只在探针里
3. **两型二选一，不许含糊**（Google SWE book）：
   - `advisory`：建议性、无强制期限，靠自愿迁移
   - `compulsory`：强制、**必须同时给迁移工具与强制截止日**，并指定推动人
   - 只发公告不给工具 = 把成本甩给用户，实践中等于永不完成
4. **三节非空是硬契约**：数据迁移 / 用户通知 / 支持期义务，只有占位符视同为空
5. **"应该没人用了"不算证据**（宪法 C2）：依赖方盘点要有调用量/引用图/遥测证据
6. **支持期要有具体到期日**：EU CRA 语境下支持期内仍须提供安全更新（默认 ≥5 年，产品预期寿命更短时以寿命为准）；口头承诺不可审计
7. **删数据前先能回来**：销毁类处置必须有备份、可逆窗口与对账校验命令
8. **退干净包含密钥与账单**（宪法 C15）：密钥吊销、权限回收、域名证书回收、账单归零，缺一即僵尸
9. **不得自行填写门禁⑤**（宪法 C14）：批准人须为人类且 ≠ 退役执行者

## 流程（六步）

### 第 0 步：入口校验
```bash
bash .claude/skills/e2e-retire/scripts/check-retire.sh specs/<feature>/ --gate-only
```
不过即停并指路（回阶段5 把门禁④走完）。

### 第 1 步：定类型与 owner
按 `templates/deprecation-template.md` 建 `specs/<feature>/deprecation.md`。
写死：`- 类型：advisory | compulsory`、退役理由、**owner 与资金**（Google 的一手教训：没有 owner 与预算的 deprecation 必然烂尾）。
选 compulsory 就同时写迁移工具路径与强制截止日。

### 第 2 步：依赖方盘点
逐个列出调用方/集成方：调用量证据 → 迁移目标 → 联系人 → 迁移状态。零依赖方也要写出**是怎么证明的**（遥测窗口、引用扫描命令）。

### 第 3 步：写三节
- **数据迁移**：每个数据集标处置（迁移/归档/销毁）+ 目标位置 + **校验方式（对账命令或判据）** + 可逆窗口 + 责任人；备份与回退写死
- **用户通知**：渠道 / 时点（提前期）/ 内容要点 / **责任人** / 送达证据；接口类退役同时上 `Sunset` 头（RFC 8594）与运行时 deprecation warning，不只靠邮件
- **支持期义务**：义务 / 起 / **止（具体日期）** / 覆盖范围（通常仅安全修复）/ 依据（合同·法规·LTS）/ 责任人

### 第 4 步：时间线与不可逆点
逐里程碑标"是否不可逆 + 回退方案"。越过不可逆点只能前滚——这一点必须在门禁⑤ 前对评审人说清楚。

### 第 5 步：退役完成核对
`- [ ] R-N <清理项> ｜ 证据：<...> ｜ 核对人：<人名>`，至少覆盖：代码与配置下线 / 基础设施·域名·证书回收 / **密钥与权限吊销** / 账单归零 / 文档标 retired 并留指路。

### 第 6 步：探针 + 停门禁⑤
```bash
bash .claude/skills/e2e-retire/scripts/check-retire.sh specs/<feature>/ --final
```
绿后输出摘要请人裁决：类型与 owner / 依赖方迁移完成率 / 三节要点 / 支持期到期日 / 不可逆点 / 剩余清理项。
- **批准** → 人类填门禁⑤记录 → 归档（留指路与复活条件）
- **打回** → 回第 3 步

## 自检清单

- [ ] 门禁④=批准 已校验，且正文写出了门禁④引用
- [ ] 类型是 advisory / compulsory 之一，compulsory 有迁移工具 + 强制截止日
- [ ] 依赖方盘点有调用量证据（不是"应该没人用"）
- [ ] 数据迁移每条有校验方式与可逆窗口；销毁类有备份
- [ ] 用户通知每条有责任人与送达证据
- [ ] 支持期义务有具体到期日与依据
- [ ] 完成核对覆盖密钥吊销与账单归零
- [ ] `--final` 探针绿；门禁⑤记录留空待人批，未自行填写
